# Подпись авторства в две строки

На экранах от 761px подпись разделена на «Идея и дизайн» (18px) и ссылку noisybrands (20px). По уточнению пользователя обе строки занимают одинаковую ширину: верхняя строка использует letter-spacing −0.154px. Измерение текстовых диапазонов после загрузки шрифта на 1366 и 1920px даёт 121px для каждой строки, левые и правые края совпадают. На телефоне сохранена одна строка размером 13px. Ссылка остаётся отдельной областью нажатия высотой 44px.

Следующее уточнение: межстрочное расстояние уменьшено. Ссылка выровнена к верху своей области нажатия с отступом 4px; расстояние между текстовыми диапазонами сократилось с 8 до 2.5px. Ширина обеих строк остаётся 121px, область нажатия — 44px. Повторные check/build успешны; снимки `*-tight-header.png` и `spacing.json` фиксируют результат на трёх ширинах.

Astro check: 0 ошибок/предупреждений/подсказок. Production build с вложенным base `/alex_evgenygrigoriev/` успешен. Просмотрены начало, середина и конец при 390×844, 1366×768 и 1920×1080; contact sheets и измерения рядом. Наложения элементов шапки, horizontal overflow и ошибок JS нет. Проверены адрес ссылки, попадание указателя, отображение в reduced motion и без JavaScript. Impeccable layout detect: пустой список. Новых зависимостей и MCP нет, использован ранее установленный Playwright/Chromium. Незакоммиченные правки текстов и прежние принятые наложения основного текста сохранены.

Граница коммита: только разметка и типографика подписи авторства и материалы её проверки. Скриншоты относятся к локальной версии страницы; отдельные незакоммиченные изменения содержания и пропорций сцен не включены. Выбранное дерево коммита отдельно проверено через Astro check и production build с вложенным base.
