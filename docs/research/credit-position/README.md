# Положение подписи дизайна

По запросу пользователя удалена ссылка «Связаться» из шапки. На экранах шире 760px подпись «Идея и дизайн noisybrands» поднята в верхнюю строку (top: 27px), на прежнюю высоту ссылки. Мобильное расположение сохранено.

Проверено: npm run check (0 ошибок), production build и Astro preview с PAGES_BASE=/alex_evgenygrigoriev/. Playwright MCP действительно вызван: снимки начала, середины и конца при 390×844, 1366×768, 1920×1080, а также reduced motion и без JavaScript. Все снимки просмотрены общей контактной таблицей. В основной матрице нет horizontal overflow, незагруженных изображений или pageerror. Tab переводит фокус на noisybrands; outline: solid. Внешний адрес ссылки сохранён: https://noisybrands.ru/.

Визуальная оценка в пределах правки: подпись выровнена с монограммой, отделена от логотипов, мобильная компоновка сохранена. Новая концепция не выбиралась. Push и публикация не выполнялись.
