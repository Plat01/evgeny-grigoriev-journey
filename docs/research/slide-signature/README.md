# Логотипы и авторство на шести слайдах

По запросу пользователя добавлен общий компонент `src/components/ChapterSignature.astro`: отдельная группа всех четырёх логотипов из `assets/logotips/` и подпись «Идея и дизайн noisybrands». Ссылка https://noisybrands.ru/ выделена насыщенностью, цветом и подчёркиванием. Компонент повторяется внутри каждой главы, включая статический режим.

Сохранено существующее направление Taste pinned-poster, seed 1363274842, и Impeccable concept seed:b889d378d2f158cf. Новый выбор направления не нужен для этой локальной правки. Идея: спокойная полоса организаций и авторская подпись составляют постоянную рамку вокруг меняющихся природных сцен. Интерактивность страницы — управление шестью сценами и внешняя ссылка авторства.

На desktop логотипы находятся рядом с монограммой, подпись справа под контактом. На телефоне подпись стоит справа от монограммы, логотипы занимают следующую строку. Позиции одинаковы на всех шести слайдах; это проверено измерениями в `qa.json`. Перекрывающая прозрачная область шапки пропускает нажатия к ссылке авторства, сами ссылки шапки остаются интерактивными.

## Исходники

Все четыре файла предоставлены пользователем; оригиналы не изменялись. `Sk_logo.png` — Сколково, `Sk_logo_2.png` — Московская школа управления Сколково, `Россети_лого.png` — Россети, `Tetra.png` — Tetra Trans. Имена организаций не превращены в новые утверждения о партнёрстве на странице.

Производные WebP в `src/assets/logotips/` обрезают только прозрачные поля, сохраняют пропорции и alpha, используют цвет ink #233d40. Буквы Sk внутри исходного зелёного квадрата сохранены вывороткой. Воспроизводимая подготовка: `node docs/research/slide-signature/prepare-logos.mjs`. Используется существующий Sharp из зависимостей Astro. Генерации и новых зависимостей нет.

- Reduced motion и отключённый JavaScript: шесть читаемых глав, все логотипы и ссылки, без закрепления и inert. Снимки целых глав сохранены, чтобы длинные статические главы были видны полностью.
- Taste lint: 0 FAIL / 0 WARN. Impeccable layout detect: пустой список. Taste inspect при 1440, 768 и 390: 0 FAIL; отчёт — `taste-report.json`. Scenes: все сцены запустились, просмотрены desktop, phone и reduced sheets.

По уточнению пользователя **наложение текста на иллюстрации на тесном экране сохранено**. Добавленный адаптивный fallback отменён, `motion.ts` возвращён к исходному media query: `no-preference` и высота от 560px. Последняя проверка 320×667 выполнена с закреплением; снимки и запись в `qa.json` обновлены. Это известное принятое ограничение, а не заявление об отсутствии наложений.

Четыре предупреждения Taste относятся к сохранённой странице: видео нет в предоставленных материалах; шесть сцен следуют заданному формату; Manrope с кириллицей закреплён текущим дизайном, несмотря на старую случайную sheet; роль человека явно указана под именем, поэтому `name-only-title` не описывает фактическое отсутствие роли. Длинные заголовки и наложение сохранены по прямым указаниям пользователя.
