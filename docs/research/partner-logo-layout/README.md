# Размер и отступ логотипов организаций

По уточнению пользователя логотипы остаются в одном ряду с EG на desktop. Их высота уменьшена с 34 до 28px, ширины — примерно на 13%. Расстояние между EG и группой увеличено с 48 до 104px; центры изображений совпадают по вертикали. Для планшета отступ увеличен с 32 до 64px. На телефоне сохранена существующая отдельная строка, размеры знаков уменьшены примерно на 11–13%. Позиция noisybrands и принятые пользователем наложения основного текста не менялись этой правкой.

Проверки: Astro check без ошибок, production build с `/alex_evgenygrigoriev/`, начало/середина/конец при 390×844, 1366×768, 1920×1080. Скриншоты и измерения — рядом; горизонтального переполнения и ошибок JS нет, все логотипы загружены. Reduced motion и отключённый JavaScript сохраняют все шесть групп. Просмотрены три contact sheets. Impeccable layout detect: пустой список; Taste lint: 0 FAIL / 0 WARN. Использован ранее установленный Playwright с отдельным Chromium; новые зависимости и MCP не добавлялись.

Граница коммита: включены только размеры и отступы логотипов и материалы этой проверки. Скриншоты показывают локальную версию; ранее внесённые правки текстов и позиции noisybrands остаются вне этого коммита. Выбранное дерево коммита проверяется отдельно через check/build.
