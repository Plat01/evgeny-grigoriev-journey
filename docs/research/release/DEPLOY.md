## Просмотр

```sh
cd ~/programming/alex/grigoriev.expert
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть `http://localhost:8000/`. Политика доступна по `/policy/`. Открытие через `file://` не подходит для проверки модулей и путей от корня.

## Пересборка из перенесённых исходников

```sh
cd ~/programming/alex/grigoriev.expert/docs/source
npm ci
npm run check
PAGES_SITE=https://grigoriev.expert PAGES_BASE=/ SITE_INDEXABLE=true npm run build
rsync -a --delete --exclude '/docs/' dist/ ../../
```

Исключение `docs/` обязательно: оно сохраняет исходники и документацию при обновлении статики. После новой сборки `docs/build.json` и `docs/qa/` описывают предыдущую поставку до повторной проверки и обновления отчётов.

## Параметры релиза

Сайт собирается с `PAGES_SITE=https://grigoriev.expert`, `PAGES_BASE=/`, `SITE_INDEXABLE=true`: canonical указывает на целевой домен, индексация разрешена. Без `SITE_INDEXABLE=true` тестовые сборки сохраняют `noindex, nofollow`. Адрес сайта внутри политики берётся из `PAGES_SITE`; исходный JSON политики, контактные данные и остальные формулировки не менялись.
