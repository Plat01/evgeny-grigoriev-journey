Добавлена строка «© 2021–2026. Все права защищены.» перед ссылкой на конфиденциальность в footer последней главы. На desktop они расположены рядом; на телефоне copyright идёт отдельной строкой над ссылкой. Отступ над навигацией сохранён. Годы указаны пользователем, автоматического изменения даты нет.

Astro check: 0 ошибок/предупреждений/подсказок. Production build с `/alex_evgenygrigoriev/` успешен. Последний экран просмотрен при 390×844, 1366×768 и 1920×1080. Измерения — `qa.json`; footer не пересекает нижнюю навигацию, horizontal overflow нет, подпись присутствует один раз. Ссылка на политику использует вложенный base. Reduced motion и отсутствие JS сохраняют обе строки. Основной текст и пропорции иллюстраций этой задачей не менялись; параллельные изменения сохранены. Новых зависимостей нет, проверка использовала установленный Playwright/Chromium.

Граница коммита: только строка copyright, её адаптивное расположение и материалы проверки. Скриншоты отражают локальное рабочее дерево; отдельные изменения текстов, масштаба сцен и подложек мобильной навигации не включены. Выбранное дерево коммита отдельно проверено через check/build.
