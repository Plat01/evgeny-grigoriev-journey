# Мобильная высота сцены — 09.11.2026

Причины: Astro Dev Toolbar включён по умолчанию в dev-режиме; сцена использовала 100svh, а ScrollTrigger игнорировал небольшие изменения высоты на touch-устройствах.

Воспроизведение в Chromium с isMobile/hasTouch: открыть страницу при 390×744, увеличить высоту до 844 без изменения ширины. До исправления закреплённая сцена оставалась высотой 744 px, оставляя 100 px под ней. См. before-resize-390.png.

Исправление: devToolbar.enabled=false в конфигурации проекта, высота активной сцены 100dvh и ScrollTrigger.config({ignoreMobileResize:false}).

Проверки:
- npm run check: 0 errors / warnings / hints.
- Production build с PAGES_SITE=https://example.github.io и PAGES_BASE=/alex_evgenygrigoriev/; просмотр через существующий production preview на порту 4324 по вложенному URL.
- Начало, середина и конец при 390×844, 1366×768, 1920×1080; изображения загружаются, horizontal overflow отсутствует, ошибок JS/console нет.
- Повторные изменения высоты 844→744→844→744→844: высота сцены совпадает с viewport после пересчёта.
- Home / PageDown переключают главы; режим reduced motion и страница без JS показывают все шесть глав без закрепления.
- Dev-сервер на порту 4321: элемент astro-dev-toolbar отсутствует.

Установлено: использован уже имеющийся Playwright/Chromium, новые зависимости не добавлялись.
Действительно вызвано: Context7 resolve-library-id/query-docs для Astro и GSAP.
Заблокировано: Playwright MCP возвращает ошибку занятого профиля при browser_tabs и browser_close; проверка выполнена через установленный Playwright в отдельном профиле без изменения MCP и чужих процессов.
Визуально проверены снимки трёх размеров и статических режимов. В коммит включены before-resize-390.png, after-resize-390.png и сводные измерения verification.json; остальные снимки сохранены локально. Эмуляция Chromium; физические телефоны и Safari недоступны. Скрытие настоящей панели мобильного браузера заменено изменением высоты viewport на touch-устройстве.

Исходные пользовательские изменения в контенте, логотипах и стилях сохранены. На этапе проверки push / deploy не выполнялись.
