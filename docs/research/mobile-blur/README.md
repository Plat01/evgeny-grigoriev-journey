# Мягкий нижний край мобильных сцен — 09.11.2026

Сохранён существующий визуальный мир и композиция. До 760px нижние 150–210px сцены постепенно размываются на 14px и растворяются в собственном `--chapter-ground`. Маска плавно вводит размытие. При отсутствии поддержки backdrop-filter остаётся цветовое затухание. Текст, footer и управление находятся выше эффекта и не размываются; сплошная полоса под управлением удалена. У текста добавлена мягкая подложка в цвет сцены, чтобы верхние ветви не пересекали последние строки главы «Любопытство».

## Проверка

- Установлено: использован существующий Playwright, ничего не устанавливалось.
- Зарегистрировано: Playwright MCP доступен в инструментах.
- Действительно вызвано: resize/navigate/close MCP вернули `Browser is already in use`; использован установленный Playwright напрямую с отдельным временным профилем Chromium, без изменения MCP и чужого профиля.
- `npm run check`: 0 errors, 0 warnings, 0 hints.
- Production build: `PAGES_SITE=https://example.github.io PAGES_BASE=/evgeny-grigoriev-journey/ npm run build` — успешно.
- Production preview: `http://127.0.0.1:4322/evgeny-grigoriev-journey/`.
- Визуально проверены все шесть сцен 390×844; начало/середина/конец при 1366×768, 1920×1080, 320×640 и 390×667; reduced motion и отсутствие JS при 390×844. Результаты измерений в `checks.json`, изображения рядом. Клавиатурный переход Home и Tab проверен.
- Нет ошибок консоли/страницы, HTTP ≥400 и horizontal overflow; все изображения загрузились. Текст не размывается, управление доступно, fallback показывает обычные главы.
- Taste inspector на production: 1440/768/390, 0 FAIL, 4 WARN. Все восемь изображений просмотрены в `inspection-sheet.jpg`. Предупреждения относятся к сохранённой композиции: шесть закреплённых иллюстрированных сцен без видео, Manrope из действующего DESIGN.md вместо старого случайного direction.json, подпись профессии под именем меньше порога 18px инспектора. Эти решения не менялись в локальной правке фона.
- Заблокировано: именно подключение Playwright MCP из-за занятого профиля. Реальные устройства и Safari не проверялись.

Нижний край стал непрерывным и мягким, текст и управление остались резкими. После первого просмотра устранено наложение ветвей под длинным текстом. В рамках изменённой области: design 8/10, usability 8/10, creativity 7/10, content 8/10; взвешенно 7.8/10.
